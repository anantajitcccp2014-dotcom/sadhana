# Садхана

Дневник садханы для Android. Работает без интернета.

- «Встал» и «Лёг» записывают время одним нажатием, длительность сна считается сама;
- джапа: круги с целью на день (+1, +4, +8, −1);
- чтение книг и повторение шлок: таймер на весь экран, пока он открыт, экран не гаснет;
- история за 14 дней, средние за неделю, график сна;
- резервная копия в файл и восстановление из него.

Записи хранятся во внутренней памяти телефона и сохраняются при обновлении приложения.

## Скачать

APK собирается автоматически при каждом изменении кода.
Последняя версия: раздел **Releases** → `Sadhana.apk`.

## Устройство

- `web/` — страница приложения (HTML, CSS, JS); `node tools/build.js` собирает её в `app/src/main/assets/index.html`
  (один раз перед этим: `cd tools && npm install`).
- `app/` — Android-оболочка: WebView, хранение записей в файле, удержание экрана, резервные копии.
- `app/sadhana.jks` — постоянный ключ подписи, чтобы новые версии ставились поверх старых.
