# Садхана

Простой дневник садханы для Android. Работает без интернета, без регистрации и рекламы.

- **Подъём и отбой** одним нажатием, длительность сна считается сама (можно отключить).
- **Свои практики** трёх видов:
  - *счётчик*: джапа, поклоны, главы; своя цель и свои кнопки (например +1 +4 +8);
  - *таймер*: чтение, повторение шлок, медитация; большой таймер на весь экран, пока он открыт, экран не гаснет;
  - *отметка «сделано»*: мангала-арати, Гаятри, экадаши и всё, что просто отмечается за день.
- История за 14 дней, средние за неделю, график сна.
- Резервная копия в файл и восстановление из неё.

Сначала в дневнике стоят: сон, джапа 16 кругов, чтение книг и повторение шлок.
Изменить набор можно в настройках (⚙ вверху справа).

## Как установить

1. Откройте на телефоне страницу **[Releases](../../releases/latest)** и скачайте `Sadhana.apk`.
2. Откройте скачанный файл. Если Android спросит, разрешите установку из этого источника (браузера или «Файлов»).
3. Нажмите «Установить». Появится иконка «Садхана» с восходящим солнцем.

Новые версии ставятся так же, поверх старой: записи сохраняются.

Записи хранятся только в вашем телефоне и никуда не отправляются.
Если удалить приложение, записи удалятся вместе с ним, поэтому время от времени делайте копию в файл (⚙ → «Сохранить копию»).

## Для разработчиков

- `web/` — страница приложения (HTML, CSS, JS). `cd tools && npm install && node build.js` собирает её в `app/src/main/assets/index.html`.
- `app/` — Android-оболочка: WebView, хранение записей в файле, удержание экрана, резервные копии.
- `app/sadhana.jks` — постоянный ключ подписи, чтобы новые версии ставились поверх старых.
- При каждом изменении в `main` GitHub Actions собирает APK и публикует его в Releases.
